# Omkar Rajamane - Developer Portfolio

A sleek, responsive, and performance-driven personal portfolio website built with modern Vanilla HTML5, CSS3, and JavaScript. Showcasing software engineering projects in Artificial Intelligence, Computer Vision, Full-Stack Web Development, and Database Systems.

---

## 🚀 Live Demo & Preview

To run and preview the portfolio locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/OmkarRajamane/my-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd my-portfolio
   ```
3. Open `index.html` in your favorite web browser (e.g. Chrome, Edge, Safari) or use VS Code Live Server.

---

## 🛠️ Tech Stack & Architecture

- **Core Technologies**: Semantic HTML5, Vanilla CSS3 (Custom Design System & CSS Variables), Modern JavaScript (ES6+)
- **Typography & Icons**: Google Fonts (Outfit, Inter, Fira Code), Font Awesome 6.5.1
- **UI / UX Features**:
  - ⚡ **Interactive Typewriter**: Dynamic role transitions in the hero section.
  - 🎨 **Modern Bento Grid**: Highlighting key metrics, CGPA, graduation timeline, and focus areas.
  - 🏷️ **Project Category Filters**: Live filtering for AI & ML, Computer Vision, and Full-Stack projects.
  - ✨ **Smooth Scroll Reveal**: Lightweight `IntersectionObserver` animations for clean entry transitions.
  - 📋 **One-Click Copy Actions**: Instant clipboard copying with feedback toasts for email and phone numbers.
  - 📱 **Fully Responsive**: Mobile-first optimized layout across phones, tablets, laptops, and desktops.
  - 🔝 **Back to Top**: Quick-navigation button with smooth scroll.
